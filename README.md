# Sunbeam-HTX-Project
Created on 8/29/26
Made by: mp17887, PrinterOven, and marshmallism (Bella Xiang)

Created for Houston Sunbeam Event

Project Description:
Theme: The Perfect Day
We decided to make a website outlining a combination of what our individual "perfect" days would look like. We chose a cozy purple theme with a miz of cozy activities and then a fun concert at the end of the day. To add a challenge, we added a scroll tracker that changed the time of the day as you go down the page.


We had a ton of fun and learned so much!
